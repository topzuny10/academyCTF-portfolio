### Intro to Assembly
###### Bit-O-Asm-1
`eax` 레지스터에 어떤 값이 들어 있는지 알아내세요. 그 값을 10진수로 변환한 다음 `academy{n}` 형식으로 답하세요. 예를 들어 값이 `0x11`이라면 10진수로 17이므로 `academy{17}`이 됩니다. 어셈블리 덤프는 여기에서 다운로드하세요.
```asm
<+0>:     endbr64
<+4>:     push   rbp
<+5>:     mov    rbp, rsp
<+8>:     mov    DWORD PTR [rbp-0x4], edi
<+11>:    mov    QWORD PTR [rbp-0x10], rsi
<+15>:    mov    eax, 0x30
<+20>:    pop    rbp
<+21>:    ret
```

``` <+15>:    mov    eax, 0x30```
을 보면 0x30의 값을 eax 레지스터에 mov, 저장하겠다는 뜻으로 eax에는 0x30, 즉 48의 값이 들어간 것을 알 수 있다.



###### Bit-O-Asm-2
어셈블리 덤프 파일을 분석하여 `eax` 레지스터에 들어갈 값을 찾아내라. 정답은 `eax` 레지스터의 값을 **10진수**로 변환한 뒤 `academy{10진수값}` 형식으로 입력하라.
```asm
<+0>:     endbr64 
<+4>:     push   rbp
<+5>:     mov    rbp,rsp
<+8>:     mov    DWORD PTR [rbp-0x14],edi
<+11>:    mov    QWORD PTR [rbp-0x20],rsi
<+15>:    mov    DWORD PTR [rbp-0x4],0x9fe1a
<+22>:    mov    eax,DWORD PTR [rbp-0x4]
<+25>:    pop    rbp
<+26>:    ret
```
rbp를 스택에 푸쉬하고, rbp에 rsp 값을 저장 -> 메모리 [rbp-0x4]에 0x9fe1a를 저장하고 eax에 저장함. 그러므로 eax의 값은 메모리에 저장한 0x9fe1a임. 10진수로 변환하면 654874.

###### Bit-O-Asm-3
마찬가지로 eax의 값을 찾고 10진수로 변환하여 입력하면 된다.
```asm
<+0>:     endbr64 
<+4>:     push   rbp
<+5>:     mov    rbp,rsp
<+8>:     mov    DWORD PTR [rbp-0x14],edi
<+11>:    mov    QWORD PTR [rbp-0x20],rsi
<+15>:    mov    DWORD PTR [rbp-0xc],0x9fe1a
<+22>:    mov    DWORD PTR [rbp-0x8],0x4
<+29>:    mov    eax,DWORD PTR [rbp-0xc]
<+32>:    imul   eax,DWORD PTR [rbp-0x8]
<+36>:    add    eax,0x1f5
<+41>:    mov    DWORD PTR [rbp-0x4],eax
<+44>:    mov    eax,DWORD PTR [rbp-0x4]
<+47>:    pop    rbp
<+48>:    ret
```

```<+15>:    mov    DWORD PTR [rbp-0xc],0x9fe1a``` [rbp-0xc]에 0x9fe1a를 저장함. 
```<+22>:    mov    DWORD PTR [rbp-0x8],0x4``` [rbp-0x8]에 0x4를 저장함.
```<+29>:    mov    eax,DWORD PTR [rbp-0xc]``` [rbp-0xc]를 eax에 저장함 -> eax는 0xfe1a.
```<+32>:    imul   eax,DWORD PTR [rbp-0x8]``` imul은 부호없는 곱셈, [rbp-0x8]을 eax에 곱함.
```<+36>:    add    eax,0x1f5``` 이후 0x1f5를 eax에 더함.
[rbp-0xc]는 654,874, [rbp-0x8]은 4, imul로 계산해 두 값을 곱함. 값은 2,619,496이 되고, 이후 0x1f5를 더함. 10진수로 501, 더하면 2,619,997. 답은 2,619,997임.

######  Bit-O-Asm-4
`eax` **레지스터에 어떤 값이 들어 있는지 알아낼 수 있나요?** 답은 `academy{n}` 형식의 플래그로 제출하세요. 여기서 `n`은 `eax` 레지스터의 값을 **10진수**로 나타낸 것입니다. 어셈블리 덤프를 다운로드하세요.
```asm
<+0>:     endbr64 
<+4>:     push   rbp
<+5>:     mov    rbp,rsp
<+8>:     mov    DWORD PTR [rbp-0x14],edi
<+11>:    mov    QWORD PTR [rbp-0x20],rsi
<+15>:    mov    DWORD PTR [rbp-0x4],0x9fe1a
<+22>:    cmp    DWORD PTR [rbp-0x4],0x2710
<+29>:    jle    0x55555555514e <main+37>
<+31>:    sub    DWORD PTR [rbp-0x4],0x65
<+35>:    jmp    0x555555555152 <main+41>
<+37>:    add    DWORD PTR [rbp-0x4],0x65
<+41>:    mov    eax,DWORD PTR [rbp-0x4]
<+44>:    pop    rbp
<+45>:    ret
```

<+8>: [rbp-0x14]에 edi를 저장.
<+11>: [rbp-0x20]에 rsi를 저장.
<+15>: [rbp-0x4]에 0x9fe1a(654874)를 저장.
<+22>: [rbp-0x4]와 0x2710(10000)을 비교(cmp).
<+29>: [rbp-0x4]와 0x2710이 작거나 같으면(jle) 메모리 주소 0x55555555514e<+37>로 점프. 
       ㄴ아니라면 <+31>: [rbp-0x4]에 저장된 0x65(101)와 뺄셈.
<+35>: 조건없이 메모리 주소 0x555555555152 <+41>로 이동.
<+41>: eax에 [rbp-0x4]를 저장.

따라서 eax의 값은 0x9fdb5, 10진수 654773가 됨.



### Deburggers
###### GDB baby step1
링크된 `debugger0_a` 파일을 **디스어셈블**해서 `main` 함수가 끝날 때 `eax` 레지스터에 들어 있는 값을 알아내세요. 그 값을 **10진수**로 바꿔 `academy{n}` 형식으로 제출하세요. 예를 들어 값이 `0x11`(16진수)이면 10진수로 17이므로 정답은 `academy{17}`입니다.
```asm
Dump of assembler code for function main:
   0x0000000000001129 <+0>: endbr64
   0x000000000000112d <+4>: push   rbp
   0x000000000000112e <+5>: mov    rbp,rsp
   0x0000000000001131 <+8>: mov    DWORD PTR [rbp-0x4],edi
   0x0000000000001134 <+11>: mov    QWORD PTR [rbp-0x10],rsi
   0x0000000000001138 <+15>: mov    eax,0x86342
   0x000000000000113d <+20>: pop    rbp
   0x000000000000113e <+21>: ret
End of assembler dump.
```

```asm 0x0000000000001138 <+15>: mov    eax,0x86342```
eax 값에 0x86342를 저장, 해당 16진수를 10진수로 변환하면 549698이 된다.

###### GDB baby step 3
이제는 조금 다른 문제입니다. **`main` 함수에서 `0x2262c96b`라는 값이 메모리에 저장됩니다.** GDB 명령어 `x/4xb addr`를 사용하여 해당 상수가 저장된 메모리를 바이트 단위로 확인하세요.
플래그는 메모리에 저장된 순서대로 네 바이트를 이어서 작성하면 됩니다. 만약 메모리 위치에서 `0x11 0x22 0x33 0x44`라는 바이트를 찾았다면 플래그는 다음과 같습니다.
`academy{0x11223344}` 주어진 파일을 디버깅하세요.
```asm
Dump of assembler code for function main:
   0x0000000000401106 <+0>: endbr64
   0x000000000040110a <+4>: push   rbp
   0x000000000040110b <+5>: mov    rbp,rsp
   0x000000000040110e <+8>: mov    DWORD PTR [rbp-0x14],edi
   0x0000000000401111 <+11>: mov    QWORD PTR [rbp-0x20],rsi
   0x0000000000401115 <+15>: mov    DWORD PTR [rbp-0x4],0x2262c96b
   0x000000000040111c <+22>: mov    eax,DWORD PTR [rbp-0x4]
   0x000000000040111f <+25>: pop    rbp
   0x0000000000401120 <+26>: ret
End of assembler dump.
```
breakpoint를 0x40111c에 걸고 run하면  ```EAX, [0x7fffffffea4c] => 0x2262c96b```로, 0x2262c96b이 주소의 실제 주소인 ```0x7fffffffea4c```가 나옴. 해당 주소로 ```x/4xb 0x7fffffffea4c```를 걸면 저장된 메모리 바이트 단위가 나옴.
```0x7fffffffea4c: 0x6b 0xc9 0x62 0x22```
답은 0x6bc96222임.
